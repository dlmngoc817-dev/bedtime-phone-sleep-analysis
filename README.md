\# Bedtime Phone Usage and Sleep Analysis



\## Overview



This beginner data analysis project explores the relationship between bedtime phone usage and sleep outcomes.



\## Questions



\- Does longer bedtime phone usage relate to fewer hours of sleep?

\- Does longer phone usage relate to greater fatigue the next day?

\- Does longer phone usage relate to taking more time to fall asleep?

\- Do sleep outcomes vary across bedtime apps?



\## Tools



\- Python

\- Pandas

\- Matplotlib

\- Seaborn

\- Jupyter Notebook



\## Key Findings



\- Longer bedtime phone usage was associated with fewer hours of sleep.

\- Longer phone usage was associated with higher fatigue scores.

\- People who used their phones longer took more time to fall asleep.

\- Differences between phone-usage-duration groups were greater than differences between bedtime-app groups.



\## Dataset



The dataset was obtained from Kaggle: \*\*Sleep Debt \& Screen Time: Late Night Phone Habits\*\*.



\## Project File



\- `bedtime\_phone\_sleep\_analysis.ipynb`: Data preparation, analysis, visualizations, findings, and conclusion.



\## Note



The results show associations and do not prove that bedtime phone usage directly causes poor sleep.
